# Recent chats

On the landing or new-chat page, select **Recent chats** above the composer. The searchable picker lists sessions from all projects, including archived chats, with the most recently active first. Each row shows its project, device, and enabled branch metadata. Search by chat title, project, branch, or device to find older sessions beyond the initial 30 results.

Click a conversation or use the arrow keys and Enter to open it. Escape or clicking outside closes the picker and leaves the new-chat draft in place. Opening a chat uses the same session navigation and worktree/service handoff as the project sidebar; workspace panels remain hidden on the landing page. Opening an archived session keeps its archived state until you explicitly resume or unarchive it.

The existing Ctrl+K command palette continues to search both commands and chats.
